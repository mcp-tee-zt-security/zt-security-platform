# 4.75 SDK Guide

## SDKs

4.75 R2 exposes a common contract surface for:

- Python: `sdk/python/`
- TypeScript: `sdk/typescript/`
- Java: `sdk/java/zt-security-sdk/`
- Go: `sdk/go/`
- CLI: `sdk/cli/ztctl.py`

## Domain coverage

SDKs cover the common governed platform lifecycle plus supporting platform capabilities:

- identity
- attestation
- capability checks
- policy evaluation
- evidence
- approvals
- execution contracts
- verification
- agents and missions
- federation
- simulations
- Kubernetes policy operations
- observability metrics and events

## Reliability behavior

The client transport layer supports bounded retries for transient HTTP responses, configurable request timeouts and idempotency keys for supported mutation requests. Applications must still choose retry semantics based on the operation's safety.

## Examples

See `sdk/examples/` for governed execution examples in Python, TypeScript, Java and Go.

## Contract-first rule

The SDK is not an independent authorization layer. Backend policy and governance remain authoritative. Client-side convenience methods must not be interpreted as granting permission to execute an action.
