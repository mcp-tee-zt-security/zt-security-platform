# 4.75 Federation

Federation is a contract boundary between organizations, trust domains or security cells.

## Model

```text
Organization
  → Trust Domain
  → Federation Policy
  → scoped exchange
  → evidence / intelligence
  → governed cross-domain action
```

## Rules

- Trust must be explicit.
- Exchange scope must be policy-bound.
- Tenant boundaries remain intact.
- Cross-domain actions require local governance and authorization.
- Evidence must identify the source and trust context.

## API surface

The SDK contract exposes organization registration and trust establishment under:

- `/v1/federation/organizations`
- `/v1/federation/trust`
