# 4.75 Kubernetes Integration

Kubernetes deployment and policy draft synchronization are documented in [the deployment guide](../../k8s/README.md). The authorization API manifests live under `k8s/deploy/`.

## Control flow

```text
ZeroTrustPolicy
  → operator reconciliation
  → POST /v1/policies (DRAFT)
  → policy version stored in the database
  → Policy Studio validation and simulation
  → explicit activation through platform governance
  → existing authorization policy evaluation
```

## Safety

The operator never activates a policy or applies workload changes. `Synced` means draft storage was acknowledged, not enforcement. Legacy workload identity/attestation/capability fields are not implemented and are rejected. Deleting a Kubernetes resource retains backend policy versions; deactivate them explicitly through the platform.
