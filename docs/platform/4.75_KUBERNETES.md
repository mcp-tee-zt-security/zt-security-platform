# 4.75 Kubernetes Integration

Kubernetes integration combines the existing `k8s/operator/` ZeroTrustPolicy CRD/operator with the 4.75 SDK contract.

## Control flow

```text
ZeroTrustPolicy
  → operator reconciliation
  → platform policy contract
  → governance decision
  → evidence
  → optional approval
  → workload/control-plane action
  → verification
```

## Safety

A Kubernetes policy resource does not bypass platform governance. High-impact changes remain subject to the configured approval boundary.
