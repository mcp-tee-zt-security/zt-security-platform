# 4.75 Simulation and Digital Twin

Simulation provides a safe evaluation boundary before a production action.

## Lifecycle

```text
Scenario
  → Simulation
  → predicted impact
  → policy evaluation
  → candidate defense
  → approval decision
  → optional execution
  → verification
```

## API

- `/v1/simulations`
- `/v1/simulations/{id}/run`

Simulation output is advisory until it passes the normal governance and execution lifecycle. A simulation must never implicitly execute its proposed action.
