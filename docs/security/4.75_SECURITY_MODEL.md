# 4.75 Security and Governance Model

## Governed action lifecycle

```text
Identity
  → Attestation
  → Capability
  → Policy Decision
  → Evidence
  → Approval
  → Execution Contract
  → Execution
  → Verification
  → Audit
```

A request may stop at any stage. A failed identity, attestation, capability or policy check must not be converted into an execution authorization.

## Trust boundaries

- Tenant and organization boundaries are explicit.
- Agent authority is capability-scoped.
- High-impact production actions require explicit approval according to policy.
- Evidence is correlated to the decision and execution that produced it.
- External integrations are treated as execution boundaries, not as implicit trust anchors.

## Agent safety

Agents may reason, correlate, simulate and recommend without receiving unrestricted production authority. Production execution must pass the same governance chain as human or service-initiated actions.

## Federation safety

Federated organizations exchange explicitly scoped information. Federation does not imply unrestricted cross-tenant access or shared administrative authority.
