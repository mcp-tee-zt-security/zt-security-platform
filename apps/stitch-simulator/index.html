사람과 Stitchy 비교

사람은 OIDC JWT, AI는 전용 서비스 계정 + 사람의 위임 세션을 사용합니다. 권한·세션을 tool arguments로 주입하지 않습니다. 검색이 ALLOW + 빈 결과이면 검색은 허용되었지만 해당 자료는 필터링된 것입니다.

권한 변경 및 차단

Allow Stitchy는 폴더의 AI 차단 설정만 해제합니다. 사람의 ACL 권한은 계속 필요합니다. Connector를 멈추고 권한을 변경하면 snapshot을 미완료로 표시하여 조회를 차단합니다. 원본의 모든 변경은 이 데모 컨트롤러를 통해 이루어집니다.

전달 내용의 보존·삭제

AI 임시 자료와 답변의 보존 시간은 60초입니다. 권한 변경 시 기존 ZT 삭제 이벤트를 실제 가상 수신자가 처리한 후 ACK합니다. 브라우저에 이미 표시된 텍스트나 사람이 저장한 자료는 회수되지 않습니다. Reset은 DB 전체 초기화가 아닌 합성 자료만 다시 동기화합니다.
